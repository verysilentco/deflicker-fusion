FlickerScope & Flicker Fusion

A meter that measures flicker the way lighting engineers do, as IEEE 1789 Percent Flicker for every pixel, and a remover that uses those measurements to rebuild each frame from its neighbours.

Slow-motion cameras sample mains-powered lamps faster than the lamps stay steady, so frames alternate between bright and dark. Generic deflickering treats this as noise. We treat it as physics: multiplicative, periodic, aliased by the frame rate, different for every light, and separate from real events like a muzzle flash.

How it works

Measure first, then remove

FlickerScope models every pixel as steady scene light multiplied by a flicker gain, Y = S · G, and fits G along optical-flow trajectories so moving people and camera motion are not mistaken for flicker. Flicker Fusion takes that gain field and rebuilds each frame from its neighbours.

FlickerScope on the range clip

Where it flickers, and by how much

The lane behind the shooter swings by up to 88%, so its darkest frames get about 14 times less light than its brightest. The shooter, lit by a different source, barely flickers at all. The meter also flags the muzzle flash as an event and leaves it out of the measurement.

Percent Flicker per pixel, (max − min) / (max + min) of the light reaching it, computed in linear light along motion. Detected frequency: 0.417 cycles per frame, which is 100 Hz at 240 fps.

Proving it

Tested against ground truth

Real footage has no "correct answer", so we built clips that do. A physics simulator relights clean video with modelled lamps (filament, fluorescent ballast, LED drivers, LED dimmers from 100 Hz to 2 kHz) on 50 or 60 Hz mains, as seen by a 120 to 480 fps camera with global or rolling shutter, highlight clipping and sensor noise. Because we know the true flicker, we can check both the meter and the remover.

Try it

Run it on your own footage

The code is on GitHub. With a CUDA GPU and the RAFT weights (see the README), one command writes the deflickered video (original audio kept), a side-by-side compare video and a flicker report:

git clone https://github.com/verysilentco/deflicker-fusion
cd deflicker-fusion
pip install -r requirements.txt
python bench/deflicker_file.py my_slowmo_clip.mov

The repository also holds the benchmark (prep.py, run.py, gate.py), the testing-grounds viewer that plays every clip and method side by side, and a small local web app. On iPhone, Deflicker: Slow Mo Flicker Fix runs this method in its Fusion engine.
